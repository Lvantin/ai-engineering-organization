
# AI Engineering Organization (AIEO)

## Overview

A reusable AI-powered software engineering organization
built on Claude Code.

The organization provides standardized AI agents,
engineering workflows, reusable skills, quality controls,
and development governance.

## Vision

Enable a small human-led organization to design,
develop, test, review, and deliver software products
through coordinated AI agents.

## Architecture

AIEO consists of two layers:

### Organization Layer

Shared engineering capabilities:
- Agent definitions
- Roles and responsibilities
- Engineering standards
- Reusable skills
- Development workflows
- Quality gates
- Governance

### Project Layer

Project-specific information:
- Product requirements
- Business context
- Solution architecture
- Technology stack
- Source code
- Test cases
- Deployment configuration

## Principles

1. Human remains accountable for product decisions.
2. Agents have explicit roles and responsibilities.
3. Requirements and architecture are documented.
4. Development follows controlled workflows.
5. Quality is validated through executable tests.
6. Organization standards are reusable across projects.
7. Every improvement is version-controlled.
