# UX Design Skill

**Version:** 1.0.0  
**Status:** Approved
**Skill ID:** ux-design

## Purpose

Create user journeys, information architecture, interaction flows, wireframes, accessibility considerations, and design specifications.

## Inputs

- Explicit task objective and scope.
- Relevant project and application/service context.
- Applicable Organization and project standards.
- Dependencies, constraints, permissions, and acceptance criteria.

## Expected capability

The Agent should:
1. Confirm the expected outcome and identify missing information.
2. Select a method appropriate to the project context.
3. Work within the assigned Role and permissions.
4. Produce reviewable artifacts.
5. Verify the result using suitable evidence.
6. Report limitations, assumptions, and risks.

## Output

A task-specific deliverable accompanied by evidence, decisions, unresolved issues, and recommended follow-up.

## Boundaries

This Skill does not grant authority beyond the Agent's assigned Role. It does not prescribe a specific programming language, framework, vendor, or runtime.

## Related Roles

Attach this Skill only to Roles for which the capability is relevant and approved. A Skill may be shared across multiple Roles without merging their accountability.
