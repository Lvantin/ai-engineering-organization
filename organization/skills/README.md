# Skills Catalog

Skills describe reusable capabilities, not job titles or permanent Agents.

A Role may use multiple Skills. A Skill may be attached to multiple Roles. Project technology context selects the concrete language/framework-specific implementation knowledge.

The initial catalog includes requirements analysis, architecture analysis, UX design, software implementation, test engineering, code quality review, security assessment, and DevOps engineering.

Technology-specific skills (for example .NET, React, Flutter, PostgreSQL, WordPress, Azure, or AWS) should be added as capability packs when there is a demonstrated need. They must not redefine the Organization Role model.
