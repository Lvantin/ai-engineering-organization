# AIEO Organization Release Workflow

**Version:** 1.0.0 | **Status:** Draft

## Purpose
Release controlled versions of Organization standards, Agent Definitions, Skills, Workflows, and runtime adapters.

## Steps
1. Collect proposed changes.
2. Classify change impact.
3. Run document, schema, and consistency checks.
4. Review role boundaries, protocol compatibility, and security impact.
5. Obtain required human approval.
6. Update version metadata and CHANGELOG.
7. Publish immutable release artifact.
8. Communicate migration notes.
9. Track project adoption and exceptions.

## Compatibility
Projects remain pinned until they deliberately adopt a new release, except where governance requires urgent risk review.
