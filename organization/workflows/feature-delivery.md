# Feature Delivery Workflow

**Version:** 1.0.0 | **Status:** Draft

## Lifecycle
1. Refinement and clarification.
2. Definition of Ready (DoR) review.
3. Product and architecture analysis.
4. Feature breakdown into User Stories and Tasks.
5. Dependency and parallelization planning.
6. Implementation.
7. Automated tests.
8. Code Review.
9. Security Review when applicable.
10. Integration and QA verification.
11. Documentation/context updates.
12. Definition of Done (DoD) review.
13. Feature acceptance and closure.

## DoR
A Feature is ready when objective, scope, acceptance criteria, impacted components, dependencies, constraints, and validation approach are sufficiently clear.

## DoD
A Feature is done when implementation and required tests are complete, reviews are resolved, integration is verified, documentation is updated, evidence is recorded, and residual risks are explicitly dispositioned.

## Separation of responsibilities
Code Review and Security Review are distinct responsibilities. QA provides test evidence. Engineering Manager coordinates but does not replace specialist validation.
