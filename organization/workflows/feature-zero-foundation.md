# Feature 0 — Technical Foundation Workflow

**Version:** 1.0.0 | **Status:** Draft

## Purpose
Establish and prove the technical foundation before broad business Feature delivery.

## Scope groups
1. Architecture and system boundaries.
2. Application structure and coding conventions.
3. Common foundation and shared capabilities.
4. Development environment and CI/CD.
5. Testing foundation.
6. Security foundation.
7. Operational foundation.
8. Documentation foundation.

## Core and Extended
- **F0 Core:** minimum foundation required to begin controlled business Feature implementation.
- **F0 Extended:** additional foundation work that can be completed incrementally when risk and project needs justify it.

## Vertical slice
Implement a small but real end-to-end technical slice to prove that the selected architecture, build, deployment path, observability, and test approach work together.

## Foundation Readiness Gate
Before broad Feature delivery, review architecture readiness, repository/build health, test automation, security baseline, deployment path, operational visibility, and required documentation.

The gate may record accepted limitations with owners and dates. It must not hide unresolved critical risks.
