## 1.0.0 — 2026-11-02 — Official baseline release

- Released the Organization Layer companion package as the first official AIEO baseline.
- Approved the 12 role-based Agent Definitions and synchronized the machine-readable Role registry.
- Approved governance, protocols, standards, Skills, workflows, templates, quality controls, and runtime adapter design guidance in this package.
- Corrected package inventory and group counts; the ZIP contains 60 files.
- Synchronized package version and release status in the README and organization manifest.
- Clarified that the three separately agreed foundational documents are required prerequisites and are not included or reconstructed here.
- Clarified that the Claude Code adapter remains a design specification and is not certified as implemented or tested.
