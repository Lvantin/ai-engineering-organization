# AIEO Organization Layer — Release Notes 1.0.0

**Status:** Official baseline release  
**Date:** 2026-11-02

## Included

This release contains the Organization Layer companion package: governance, 12 Agent Definitions, three protocols, nine engineering standards, the Skills catalog and eight Skills, six workflows, eight templates, four quality documents, two integration design documents, two JSON configuration files, and versioning records.

## Required companion documents

The target repository must also contain the separately agreed foundational documents:

- `organization/vision.md`
- `organization/operating-model.md`
- `organization/roles-and-responsibilities.md`

They are not included in this ZIP because their previously agreed content must be preserved rather than reconstructed from a summary.

## Important limitations

- Claude Code adapter content is a design specification only.
- No claim is made that a runtime integration, agent bootstrap, hooks, or end-to-end workflow has been implemented or tested.
- This artifact has not been committed or tagged in the user's GitHub repository by this release operation.

## Upgrade guidance

New projects may adopt AIEO 1.0.0 after adding the three required foundational documents and reviewing the package. Existing projects should record the adopted AIEO version and upgrade deliberately, following their own impact assessment.
